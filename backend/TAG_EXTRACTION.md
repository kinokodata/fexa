# タグ抽出ツール

## 概要

このツールは基本情報技術者試験の問題文と選択肢からIT関連のキーワードを自動抽出し、tagsテーブルに登録します。

## 機能

### 1. キーワード抽出
- **問題文**: 各問題の本文からIT用語を抽出
- **選択肢**: すべての選択肢テキストからIT用語を抽出
- **重複排除**: 同じ問題内で重複するキーワードを除去

### 2. カテゴリ分類
抽出されるキーワードは以下のカテゴリに分類されます：
- **ネットワーク**: TCP/IP, HTTP, DNS, SSL/TLS など
- **セキュリティ**: 暗号化, 認証, ファイアウォール など
- **データベース**: SQL, JOIN, トランザクション など
- **プログラミング**: オブジェクト指向, アルゴリズム など
- **システム開発**: ウォーターフォール, アジャイル など
- **ハードウェア**: CPU, メモリ, SSD など

### 3. 優先度設定
- **high**: 重要度の高い基本用語（relevance_score: 1.0, is_primary: true）
- **medium**: 中程度の用語（relevance_score: 0.8, is_primary: false）
- **low**: 低めの用語（relevance_score: 0.6, is_primary: false）

## 使用方法

### 全年度・全季節を処理
```bash
# npmスクリプト経由
npm run extract-tags

# 直接実行
node extract-tags.js
```

### 特定の年度・季節のみ処理
```bash
# 2023年春期のみ
npm run extract-tags:year 2023 春期

# 2023年秋期のみ  
npm run extract-tags:year 2023 秋期

# 直接実行
node extract-tags.js 2023 春期
node extract-tags.js 2023 秋期
```

## 処理フロー

1. **試験データ取得**: 指定された年度・季節の試験を検索
2. **問題一覧取得**: 該当試験のすべての問題と選択肢を取得
3. **キーワード抽出**: 問題文と選択肢からIT用語を抽出
4. **タグ作成**: 新しいキーワードはtagsテーブルに登録
5. **関連付け**: question_tagsテーブルで問題とタグを関連付け

## 出力例


## データベース影響

### tagsテーブル
- 新しいキーワードが発見された場合、自動的にレコードを作成
- `name`: 正規化されたタグ名（英数字_アンダースコア）
- `display_name`: 元のキーワード表記
- `description`: カテゴリ情報付きの説明
- `category_id`: NULL（後で手動設定）

### question_tagsテーブル
- 問題とタグの関連を作成
- 既存の関連は重複作成されない
- `created_by`: 'auto_extraction'で識別可能

## 注意事項

### 1. 処理時間
- 各問題の処理後に1秒の待機時間
- 80問の場合、約1.5分程度かかります

### 2. API制限
- Supabaseの制限に配慮した実装
- エラーが発生した場合は個別にログ出力

### 3. 既存データ
- 既存のタグや関連は保護されます
- 重複チェックにより安全に実行可能

### 4. キーワード辞書
- `IT_KEYWORDS`オブジェクトで管理
- 必要に応じて辞書を拡張可能

## 拡張方法

### キーワード追加
```javascript
const IT_KEYWORDS = {
  // 新しいキーワードを追加
  'API': { category: 'ネットワーク', priority: 'high' },
  'REST': { category: 'ネットワーク', priority: 'medium' },
  // ...
};
```

### カテゴリ追加
新しいカテゴリを追加する場合は、キーワード辞書に新しいカテゴリ名を追加してください。

## トラブルシューティング

### 環境変数エラー
```
SUPABASE_URLまたはSUPABASE_ANON_KEYが設定されていません
```
→ `.env`ファイルでSupabaseの設定を確認してください。

### 試験が見つからない
```
試験が見つかりません: 2023年春期
```
→ データベースに該当する試験データが存在するか確認してください。

### タグ作成エラー
個別のタグ作成エラーはログに出力されますが、処理は継続されます。
