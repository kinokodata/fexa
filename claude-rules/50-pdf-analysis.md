# PDF解析ルール

基本情報技術者試験のPDFから問題データを抽出し、markdown形式で出力する作業です。

## 基本方針

1. チャットにアップロードされたPDFを読み込み、解析する。
2. プロジェクトナレッジの `text-data.md サンプル` と同じ形式でアーティファクトとして出力する。

## 出力形式ルール

* `# 見出し` は試験情報（例： 平成28年度 春期 基本情報技術者試験 午前 問題）
* 問題番号は `## 見出し` とする
* 数式はKatex記法を使用する
* 簡単な表はMarkdownテーブルで表現し、複雑な図表は画像として扱う
* 選択肢は箇条書き（- ア、イ、ウ、エ）で表記する
  * サンプルどおりに出力すること。`- ア.` のように `.` を**置かない**

## 数式・計算ルール

* 数式は必ずKatex記法（$...$）で記述する
* 分数は `$\frac{分子}{分母}$` 形式で表現する
* 指数は `$2^{256}$` のような形式で表現する

## 画像・図表の処理ルール

* 複雑な図表・グラフ・画像は全て画像ファイルとして扱う
* 画像リンクは以下の形式で記述する：
    - `![図表の説明](./images/<問番号>_<連番>.png)`
    - 例: `![ネットワーク構成図](./images/q15_1.png)`
    - 例: `![処理フローチャート](./images/q23_2.png)`
* ALTテキストには図表の内容を詳細に記述する
* 表、グラフ、図解、写真、イラスト、フローチャート等すべてを対象とする
* 1つの問題に複数の図表がある場合は連番（_* _* _3...）で管理する
* 実際の画像ファイルはSupabase Storageに保存する

## 特殊要素の処理

* 表紙や目次は不要
* 注意事項や凡例は不要
* メモ用紙などの空白ページは不要
* 著作権表示や試験情報は不要

## 解答・解説ルール

### 基本方針

* 解答生成では自動化ツールやスクリプトを使用せず、ClaudeのAI分析のみで実行する
* 各問題の内容を技術的に分析
* IT知識に基づいて正解を決定 
* 日本語で詳細な解説を生成
* 各問題の選択肢の後に、正解と解説を直接追記する

### 正解決定基準

- 基本情報技術者試験レベルのIT知識を適用
- アルゴリズム、データ構造、ネットワーク、セキュリティ、データベース等の分野
- 論理的推論と技術的正確性を重視

### 解説生成基準

- 日本語で記述
- ヘッダー・フッター不要（`## 解説` は書かない）
- 技術的根拠を明確に説明
- 他の選択肢が不適切である理由も説明
- 基本情報の合格を目指す学習者に有用な、簡潔で教育的な内容
- ClaudeのAI知識で詳細に記述（効率より品質重視）

## **重要：**大容量PDF処理ルール

* PDFは一度に全部読まずに、10ページずつ段階的に処理する
* 各10ページごとにアーティファクトを作成する
  * yyyy年春/秋/特別_問N-問M のように作成
* メモリ効率を考慮し、大きなPDFも安定して処理できるようにする

## 出力例

```markdown
# 平成22年度春期 基本情報技術者試験 午前問題 解答・解説

## 問1
16進小数2A.4Cと等しいものはどれか。

- ア $2^5+2^3+2^1+2^{-2}+2^{-5}+2^{-6}$
- イ $2^5+2^3+2^1+2^{-1}+2^{-4}+2^{-5}$
- ウ $2^6+2^4+2^2+2^{-2}+2^{-5}+2^{-6}$
- エ $2^6+2^4+2^2+2^{-1}+2^{-4}+2^{-5}$

**正解: ア**

16進数2A.4Cを2進数に変換すると、2A₁₆ = 00101010₂、4C₁₆ = 01001100₂となる。
よって2A.4C₁₆ = 00101010.01001100₂ = $2^5+2^3+2^1+2^{-2}+2^{-5}+2^{-6}$
```
