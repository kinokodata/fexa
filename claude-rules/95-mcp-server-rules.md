# MCPサーバ開発・運用ルール

## MCPサーバの概要
- Model Context Protocol (MCP) サーバを使用してデータベース操作を実行
- Supabaseとの安全な接続を提供
- Claude Codeから直接データベース操作を可能にする

## 開発ルール

### ファイル構造
- MCPサーバは `mcp-servers/` ディレクトリに配置
- 各サーバは独立したディレクトリとして管理
- `package.json`, メインファイル, 設定ファイルを含む

### 実装ルール
1. **セキュリティ第一**
   - 環境変数による機密情報管理
   - Service Key使用時の適切な権限設定
   - SQLインジェクション対策の徹底

2. **エラーハンドリング**
   - 詳細なエラーメッセージの提供
   - 適切なログ出力
   - 失敗時のロールバック処理

3. **データ整合性**
   - トランザクション処理の活用
   - 制約違反の適切な処理
   - データベーススキーマとの整合性確保

## 運用ルール

### 接続管理
- Supabaseクライアントの適切な初期化
- 接続プールの効率的な利用
- タイムアウト設定の最適化

### パフォーマンス
- バッチ処理での大量データ操作
- インデックスを考慮したクエリ設計
- 不要なデータ取得の回避

### メンテナンス
- 定期的なログ確認
- パフォーマンス監視
- セキュリティ更新の適用

## 使用時のルール

### データ操作
- 大量データ変更時は事前確認
- バックアップの確認
- 段階的な実行（テスト → 本実行）

### デバッグ
- MCPサーバのログ確認
- Supabaseダッシュボードでの検証
- エラー発生時の詳細調査

## 禁止事項
- 本番データでの無計画な実験
- 認証情報のハードコーディング
- 制約を無視したデータ操作
- 大量データの一括削除（慎重な検討が必要）
