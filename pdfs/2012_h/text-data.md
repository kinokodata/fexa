## 問1

次の10進小数のうち、8進数に変換したときに有限小数になるものはどれか。

- ア. 0.3
- イ. 0.4
- ウ. 0.5
- エ. 0.8

**正解: ウ**

10進小数を8進数に変換したときに有限小数になるのは、その数が8の負のべき乗の和で表現できる場合です。0.5 = 1/2 = 4/8なので、8進数では0.4となり有限小数になります。0.3、0.4、0.8は8進数に変換すると循環小数になります。

## 問2

非負の2進数 $b_1b_2 \cdots b_n$ を3倍にしたものはどれか。

- ア. $b_1b_2 \cdots b_n 0 + b_1b_2 \cdots b_n$
- イ. $b_1b_2 \cdots b_n 00 - 1$
- ウ. $b_1b_2 \cdots b_n 000$
- エ. $b_1b_2 \cdots b_n 1$

**正解: ア**

2進数を1ビット左シフトすると2倍になります。$b_1b_2 \cdots b_n 0$は元の数の2倍です。これに元の数$b_1b_2 \cdots b_n$を加えると、2倍+1倍=3倍となります。

## 問4

後置記法（逆ポーランド記法）では、例えば、式 $Y = (A - B) \times C$ を $YAB - C\times =$ と表現する。次の式を後置記法で表現したものはどれか。

$Y = (A + B) \times (C - D \div E)$

- ア. $YAB + C - DE \div \times =$
- イ. $YAB + CDE \div - \times =$
- ウ. $YAB + EDC \div - \times =$
- エ. $YBA + CD - E \div \times =$

**正解: イ**

後置記法では演算子を被演算子の後に置きます。$(A + B)$は$AB+$、$(D \div E)$は$DE\div$、$(C - D \div E)$は$CDE\div-$、全体は$AB+CDE\div-\times$となり、代入は$YAB+CDE\div-\times=$となります。

## 問6

十分な大きさの配列 $A$ と初期値が0の変数 $p$ に対して、関数 $f(x)$ と $g()$ が次のとおり定義されている。配列 $A$ と変数 $p$ は、関数 $f(x)$ と $g()$ だけでアクセス可能である。これらの関数が操作するデータ構造はどれか。

```javascript
function f(x) {
    p = p + 1;
    A[p] = x;
    return None;
}

function g() {
    x = A[p];
    p = p - 1;
    return x;
}
```

- ア. キュー
- イ. スタック
- ウ. ハッシュ
- エ. ヒープ

**正解: イ**

$f(x)$はpをインクリメントしてからデータを格納（push操作）、$g()$は現在位置のデータを取り出してからpをデクリメント（pop操作）しています。これはLIFO（Last In First Out）の動作であり、スタックの実装です。
