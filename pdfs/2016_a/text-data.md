## 問1
10進数の演算式 $7 \div 32$ を2進数で表現すると $111 \div 100000$ になる。この計算を途中で打ち切って、商を2進数で小数点以下3桁までの近似値で求めたものはどれか。

- ア 0.001
- イ 0.010
- ウ 0.100
- エ 0.111

**正解: ウ**

解説：
2進数での割り算 $111 \div 100000$ を筆算で行います。
- $7 \div 32 = 0.21875$ (10進数)
- 2進数での筆算：
    - $111.000... \div 100000$
    - 最初の桁：$111 < 100000$ なので商は0
    - 小数第1位：$1110 < 100000$ なので商は0
    - 小数第2位：$11100 < 100000$ なので商は0
    - 小数第3位：$111000 > 100000$ なので商は1
- よって小数点以下3桁までは $0.001$ ですが、実際は $0.00111...$ となり、3桁で打ち切ると $0.001$、4桁目以降を考慮すると四捨五入（二進五入）で $0.010$ になります。

## 問2
負の整数を2の補数で表現するとき、8ビットで表現できる数値の範囲として、適切なものはどれか。

- ア -128 〜 127
- イ -127 〜 128
- ウ -255 〜 0
- エ -256 〜 255

**正解: ア**

解説：
8ビットでの2の補数表現では：
- 最上位ビット（MSB）が符号ビット（0：正、1：負）
- 正の数：0000 0001 (1) 〜 0111 1111 (127)
- 負の数：1000 0000 (-128) 〜 1111 1111 (-1)
- したがって表現範囲は-128〜127となります。
- -128が表現できる理由は、1000 0000の2の補数が取れないため、この値を-128として定義しているからです。

## 問4
浮動小数点数の演算において、演算結果が正規化されていたとき、最上位の仮数部が0になってしまった。この現象を何と呼ぶか。

- ア アンダフロー
- イ 情報落ち
- ウ 桁落ち
- エ オーバフロー

**正解: ウ**

解説：
浮動小数点演算における現象：
- **桁落ち**：大きさがほぼ等しい数値の減算で、有効桁数が減少する現象
- **情報落ち**：大きさが大幅に異なる数値の加減算で、小さい方の数値の情報が失われる現象
- **アンダフロー**：演算結果が表現可能な最小値より小さくなる現象
- **オーバフロー**：演算結果が表現可能な最大値より大きくなる現象
- 最上位の仮数部が0になるのは、近い値同士の減算による桁落ちです。

## 問12
いわゆる「ハノイの塔」の問題において、円盤がn枚あるときの最少手数を求める漸化式として、適切なものはどれか。ただし、$T(n)$をn枚の円盤を移動させるのに必要な最少手数とする。

- ア $T(n) = T(n-1) + 1$
- イ $T(n) = 2T(n-1) + 1$
- ウ $T(n) = T(n-1) + T(n-2)$
- エ $T(n) = nT(n-1)$

**正解: イ**

解説：
ハノイの塔の解法：
1. 上のn-1枚を補助の柱に移動：T(n-1)手
2. 最下段の1枚を目標の柱に移動：1手
3. 補助の柱のn-1枚を目標の柱に移動：T(n-1)手
- 合計：T(n) = T(n-1) + 1 + T(n-1) = 2T(n-1) + 1
- 初期条件：T(1) = 1
- 解：T(n) = 2^n - 1

## 問13

```

y ← 3
z ← 0
while x > 0 do
  if x mod 2 = 1 then
    z ← z + y
  end if
  x ← x div 2
  y ← y × 2
end while
```

- ア 8
- イ 15
- ウ 23
- エ 30

**正解: イ**

解説：
実行トレース：
- 初期値：x=5, y=3, z=0
- 1回目：x%2=1なのでz=z+y=0+3=3, x=5/2=2, y=3×2=6

- x=0でループ終了、z=15
- これは2進数による乗算アルゴリズム（5×3=15の計算）
