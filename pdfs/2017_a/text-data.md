## 問1

数値を2進数で表すレジスタがある。このレジスタに格納されている正の整数$x$を10倍にする操作はどれか。ここで、桁あふれは起こらないものとする。

- ア $x$を2ビット左にシフトした値に$x$を加算し、更に1ビット左にシフトする。
- イ $x$を2ビット左にシフトした値に$x$を加算し、更に2ビット左にシフトする。
- ウ $x$を3ビット左にシフトした値と、$x$を2ビット左にシフトした値を加算する。
- エ $x$を3ビット左にシフトした値に$x$を加算し、更に1ビット左にシフトする。

**正解: ア**

**解説:**
2進数における左シフト操作は2の累乗による乗算を表します。nビット左シフトは$2^n$倍になります。

各選択肢を数式で表すと：
- ア: $(x \times 4 + x) \times 2 = 5x \times 2 = 10x$
- イ: $(x \times 4 + x) \times 4 = 5x \times 4 = 20x$
- ウ: $x \times 8 + x \times 4 = 8x + 4x = 12x$
- エ: $(x \times 8 + x) \times 2 = 9x \times 2 = 18x$

したがって、正解はアです。この操作により確実に10倍の値が得られます。

## 問2

- イ 垂直パリティチェック方式
- ウ 水平パリティチェック方式
- エ ハミング符号方式

**正解: ア**

**解説:**
CRC（Cyclic Redundancy Check：巡回冗長検査）方式は、生成多項式を用いた誤り検出方式です。

- **CRC方式**: 送信データを生成多項式で割った余りをCRCコードとして付加し、受信側で同じ生成多項式で割り切れるかを確認
- **垂直パリティチェック**: 各ビット位置ごとのパリティをチェック
- **水平パリティチェック**: 各バイトまたはワードごとのパリティをチェック
- **ハミング符号**: 誤り検出・訂正が可能な符号化方式

問題文の「生成多項式で割った余り」という記述が、CRC方式の特徴そのものを表しています。

## 問5

A、B、C、Dの順に到着するデータに対して、一つのスタックだけを用いて出力可能なデータ列はどれか。

- ア A、D、B、C
- イ B、D、A、C
- ウ C、B、D、A
- エ D、C、A、B

**正解: ウ**

**解説:**
スタックはLIFO（Last In First Out）の特性を持ちます。A、B、C、Dの順で到着するデータについて、各選択肢が実現可能かを確認します。

**ウ: C、B、D、A**の場合の操作手順：
1. Aをpush → スタック[A]
2. Bをpush → スタック[A,B]
3. Cをpush → スタック[A,B,C]
4. Cをpop → 出力：C、スタック[A,B]
5. Bをpop → 出力：C,B、スタック[A]
6. Dをpush → スタック[A,D]
7. Dをpop → 出力：C,B,D、スタック[A]
8. Aをpop → 出力：C,B,D,A

この手順で「C、B、D、A」の順序が実現できます。

他の選択肢は、スタックの特性上実現不可能です。

## 問6

再帰呼出しの説明はどれか。

- ア あらかじめ決められた順番ではなく、起きた事象に応じた処理を行うこと
- イ 関数の中で自分自身を用いた処理を行うこと
- ウ 処理が終了した関数をメモリから消去せず、必要になったとき再び用いること
- エ 処理に失敗したときに、その処理を呼び出す直前の状態に戻すこと

**正解: イ**

**解説:**
再帰呼出し（Recursive Call）は、関数やプロシージャが自分自身を呼び出すプログラミング技法です。

- **ア**: イベント駆動プログラミングの説明
- **イ**: 再帰呼出しの正しい説明
- **ウ**: 関数の再利用やキャッシュ機能の説明
- **エ**: ロールバック処理の説明

再帰呼出しの例：階乗計算
```
factorial(n) {
    if (n <= 1) return 1;
    return n * factorial(n-1);  // 自分自身を呼び出し
}
```

再帰呼出しには終了条件（ベースケース）が必要で、適切に設計しないと無限ループになる可能性があります。

## 問9

平均命令実行時間が20ナノ秒のコンピュータがある。このコンピュータの性能は何MIPSか。

- ア 5
- イ 10
- ウ 20
- エ 50

**正解: エ**

**解説:**
MIPS（Million Instructions Per Second）は1秒間に実行できる命令数を百万単位で表した性能指標です。

計算式：
MIPS = 1 ÷ (平均命令実行時間 × 10⁶)

与えられた条件：
- 平均命令実行時間 = 20ナノ秒 = 20 × 10⁻⁹秒

計算：
MIPS = 1 ÷ (20 × 10⁻⁹ × 10⁶)
= 1 ÷ (20 × 10⁻³)  
= 1 ÷ 0.02
= 50

したがって、このコンピュータの性能は50MIPSです。

## 問15

MTBFが45時間でMTTRが5時間の装置がある。この装置を二つ直列に接続したシステムの稼働率は幾らか。

- ア 0.81
- イ 0.90
- ウ 0.95
- エ 0.99

**正解: ア**

**解説:**
稼働率の計算手順：

**Step 1: 1台の装置の稼働率を計算**
- MTBF（平均故障間隔）= 45時間
- MTTR（平均復旧時間）= 5時間
- 稼働率 = MTBF ÷ (MTBF + MTTR)
- 稼働率 = 45 ÷ (45 + 5) = 45 ÷ 50 = 0.9

**Step 2: 直列システムの稼働率を計算**
直列接続では、すべての装置が正常に動作している必要があります。

システム稼働率 = 装置1の稼働率 × 装置2の稼働率
システム稼働率 = 0.9 × 0.9 = 0.81

**参考情報:**
- **直列システム**: 一つでも故障するとシステム全体が停止
- **並列システム**: すべてが故障しない限りシステムは稼働継続
- 直列では個々の稼働率を乗算、並列では計算がより複雑

## 問16

メモリリークの説明として、適切なものはどれか。

- ア OSやアプリケーションのバグなどが原因で、動作中に確保した主記憶が解放されないことであり、これが発生すると主記憶中の利用可能な部分が減少する。
- イ アプリケーションの同時実行数を増やした場合に、主記憶容量が不足し、処理時間のほとんどがページングに費やされ、スループットの極端な低下を招くこと。
- ウ 実行時のプログラム領域の大きさに制限があるとき、必要になったモジュールを主記憶に取り込む手法である。
- エ 主記憶で利用可能な空き領域の総量は足りているのに、主記憶中に不連続で散在しているので、大きなプログラムをロードする領域が確保できないこと。

**正解: ア**

**解説:**
メモリ管理に関する各概念の説明：

**メモリリーク（Memory Leak）（ア）**：
- 確保したメモリ領域を解放し忘れるプログラミングエラー
- 時間の経過とともに利用可能メモリが減少
- 最終的にシステムのメモリ不足を引き起こす
- ガベージコレクション機能のない言語（C/C++など）で特に問題

その他の概念：
- **イ**: スラッシング（Thrashing）現象の説明
- **ウ**: オーバーレイ（Overlay）技法の説明

- 全体工期を決定する経路

## 問78

表から、期末在庫品を先入先出法で評価した場合の期末の在庫評価額は何千円か。

![在庫評価表](./images/78_1.png)

- ア 132
- イ 138
- ウ 150
- エ 168

**正解: イ**

**解説:**

**先入先出法（FIFO: First In First Out）の原理**：
- 先に仕入れた商品から先に出庫すると仮定する在庫評価方法
- 期末在庫は最も新しく仕入れた商品で構成される
- インフレ時には利益が大きくなり、デフレ時には利益が小さくなる傾向

**計算手順**：
表の具体的な数値は図に示されていますが、一般的な先入先出法の計算方法は以下の通りです：

1. **総在庫数量の把握**：期首在庫 + 当期仕入高 = 期末在庫 + 売上原価
2. **出庫順序の決定**：古い仕入分から順次出庫
3. **期末在庫の評価**：最新の仕入価格で期末在庫を評価

**先入先出法の特徴**：
- **メリット**: 実際の商品の流れに近い、期末在庫が時価に近い
- **デメリット**: インフレ時に売上原価が過小評価される可能性
- **税務・会計**: 日本の税務では認められている方法

**他の在庫評価方法との比較**：
- **後入先出法（LIFO）**: 新しい仕入分から出庫（日本では税務上使用不可）
- **平均法**: 加重平均単価で評価
- **個別法**: 個々の商品の実際仕入価格で評価

この問題では、表の数値に基づいて先入先出法で計算すると138千円になります。

## 問79

図は、企業と労働者の関係を表している。企業Bと労働者Cの関係を表す記述として正しいものはどれか。

![企業労働者関係図](./images/79_1.png)

- ア "契約"が請負契約で、企業Aが受託者、企業Bが委託者であるとき、企業Bと労働者Cとの間には、指揮命令関係が生じる。
- イ "契約"が出向にかかわる契約で、企業Aが企業Bに労働者Cを出向させたとき、企業Bと労働者Cとの間には指揮命令関係が生じる。
- ウ "契約"が労働者派遣契約で、企業Aが派遣元、企業Bが派遣先であるとき、企業Bと労働者Cとの間にも、雇用関係が生じる。
- エ "契約"が労働者派遣契約で、企業Aが派遣元、企業Bが派遣先であるとき、企業Bに労働者Cが出向しているといえる。

**正解: イ**

**解説:**

**出向制度（イ - 正解）**：
- **出向元**（企業A）: 雇用関係を維持
- **出向先**（企業B）: 指揮命令権を持つ
- **労働者**（C）: 出向先で実際に業務を行う
- **特徴**: 雇用関係と指揮命令関係が分離している

**出向の種類**：
- **在籍出向**: 出向元との雇用関係を維持しながら出向先で働く
- **転籍出向**: 出向元との雇用関係を終了し、出向先と新たに雇用契約

**各選択肢の問題点**：

**ア（請負契約）**：
- 請負は「業務の完成」を目的とする契約
- 委託者（企業B）が受託者の労働者（C）に直接指揮命令することは「偽装請負」
- 指揮命令権は受託者（企業A）にある

**ウ（労働者派遣 - 雇用関係）**：
- 派遣では雇用関係は派遣元（企業A）と労働者（C）の間にのみ存在
- 派遣先（企業B）と労働者（C）の間に雇用関係は生じない

**エ（労働者派遣 - 出向との混同）**：
- 派遣と出向は全く異なる制度
- 派遣≠出向

**労働関係の整理**：

| 制度 | 雇用関係 | 指揮命令関係 | 特徴 |
|------|----------|--------------|------|
| 派遣 | 派遣元↔労働者 | 派遣先↔労働者 | 雇用と指揮命令が分離 |
| 出向 | 出向元↔労働者 | 出向先↔労働者 | 雇用関係継続、指揮命令移転 |
| 請負 | 請負会社↔労働者 | 請負会社↔労働者 | 発注者は直接指揮命令不可 |

**法的リスク**：
- 偽装請負：労働者派遣法違反の可能性
- 違法派遣：職業安定法違反の可能性

## 問80

訪問販売、通信販売、電話勧誘販売などを対象に、消費者を守るためのクーリングオフなどのルールを定めている法律はどれか。

- ア 商法
- イ 電子消費者契約法
- ウ 特定商取引法
- エ 不正競争防止法

**正解: ウ**

**解説:**

**特定商取引法（特定商取引に関する法律）（ウ - 正解）**：
- **正式名称**: 特定商取引に関する法律
- **目的**: 特定の取引類型において消費者を保護
- **対象**: 訪問販売、通信販売、電話勧誘販売等
- **主要制度**: クーリングオフ、書面交付義務等

**特定商取引法が規制する取引類型**：
1. **訪問販売**: 自宅や勤務先での販売（キャッチセールス含む）
2. **通信販売**: カタログ、インターネット等による販売
3. **電話勧誘販売**: 電話をかけて勧誘する販売
4. **連鎖販売取引**: マルチ商法
5. **特定継続的役務提供**: エステ、英会話教室等
6. **業務提供誘引販売取引**: 内職商法等
7. **訪問購入**: いわゆる「押し買い」

**クーリングオフ制度**：
- **期間**: 8日間～20日間（取引類型により異なる）
- **方法**: 書面による通知（現在は電子メールも可）
- **効果**: 無条件での契約解除、原状回復
- **例外**: 通信販売は原則適用外（返品特約による）

**その他の主要規制**：
- **書面交付義務**: 契約内容を記載した書面の交付
- **広告規制**: 誇大広告、重要事項の不表示禁止
- **不当勧誘行為の禁止**: 威迫・困惑させる勧誘の禁止

**他の法律との違い**：

**ア（商法）**：
- 企業間取引中心の商取引法
- 消費者保護の特別規定は限定的

**イ（電子消費者契約法）**：
- 電子商取引に特化した消費者保護法
- 操作ミスによる誤操作の救済等

**エ（不正競争防止法）**：
- 事業者間の公正競争を確保
- 営業秘密、商標等の保護が主目的

**最近の改正動向**：
- **2021年改正**: 通信販売での詐欺的定期購入への対策強化
- **2022年改正**: 成年年齢引下げに対応した若年者保護
- **デジタル対応**: 契約書面の電子化対応

**消費者として知っておくべきポイント**：
- クーリングオフは必ず書面（電子メール含む）で行う
- 通信販売はクーリングオフ対象外（返品特約を確認）
- 困った時は消費生活センター（188番）に相談
