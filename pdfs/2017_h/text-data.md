## 問1

集合 $A$, $B$, $C$ を使った等式のうち，集合 $A$, $B$, $C$ の内容によらず常に成立する等式はどれか。ここで，$\cup$は和集合，$\cap$は積集合を示す。

- ア. $(A \cup B) \cap (A \cap C) = B \cap (A \cup C)$
- イ. $(A \cup B) \cap C = (A \cup C) \cap (B \cup C)$
- ウ. $(A \cap C) \cup (B \cap A) = (A \cap B) \cup (B \cap C)$
- エ. $(A \cap C) \cup (B \cap C) = (A \cup B) \cap C$

**正解: エ**

これは分配法則の問題です。$(A \cap C) \cup (B \cap C) = (A \cup B) \cap C$は積集合の分配法則として常に成立します。この式は「CかつAまたはCかつB」が「CかつAまたはB」と等しいことを示しており、集合論の基本法則の一つです。他の選択肢は特定の条件下でのみ成立するか、恒等式ではありません。

## 問2

0 以外の数値を浮動小数点表示で表現する場合，仮数部の最上位桁が 0 以外になるように，桁合わせする操作はどれか。ここで，仮数部の表現方法は，絶対値表現とする。

- ア. 切上げ
- イ. 切捨て
- ウ. 桁上げ
- エ. 正規化

**正解: エ**

浮動小数点数において、仮数部の最上位桁を0以外にする操作を正規化といいます。例えば、0.001234×10³を1.234×10⁰に変換することが正規化です。これにより仮数部の精度を最大限に活用でき、数値の表現精度が向上します。切上げ・切捨ては丸め処理、桁上げは加算時の処理であり、正規化とは異なります。

## 問3

$X$ と $Y$ の否定論理積 $X$ NAND $Y$ は，NOT$(X$ AND $Y)$として定義される。

$X$ OR $Y$ を NAND だけを使って表した論理式はどれか。

- ア. $((X$ NAND $Y)$ NAND $X)$ NAND $Y$
- イ. $(X$ NAND $X)$ NAND$(Y$ NAND $Y)$
- ウ. $(X$ NAND $Y)$ NAND$(X$ NAND $Y)$
- エ. $X$ NAND$(Y$ NAND$(X$ NAND $Y))$

**正解: イ**

NANDのみでOR演算を実現する問題です。まず$X$ NAND $X$は$\overline{X \cdot X} = \overline{X}$（Xの否定）、$Y$ NAND $Y$は$\overline{Y}$（Yの否定）になります。次に$(\overline{X})$ NAND $(\overline{Y}) = \overline{\overline{X} \cdot \overline{Y}}$となり、ド・モルガンの法則により$\overline{\overline{X} \cdot \overline{Y}} = X + Y$（XまたはY）となります。これによりOR演算が実現できます。

## 問4

データ構造の一つであるリストは，配列を用いて実現する場合と，ポインタを用いて実現する場合とがある。配列を用いて実現する場合の特徴はどれか。ここで，配列を用いたリストは，配列に要素を連続して格納することによって構成し，ポインタを用いたリストは，要素から次の要素へポインタで連結することによって構成するものとする。

- ア. 位置を指定して，任意のデータに直接アクセスすることができる。
- イ. 並んでいるデータの先頭に任意のデータを効率的に挿入することができる。
- ウ. 任意のデータの参照は効率的ではないが，削除や挿入の操作を効率的に行える。
- エ. 任意のデータを別の位置に移動する場合，隣接するデータを移動せずにできる。

**正解: ア**

配列を用いたリストの最大の特徴は、インデックスを使った直接アクセス（ランダムアクセス）が可能なことです。O(1)の時間でi番目の要素にアクセスできます。一方、ポインタを使った連結リストは先頭から順次辿る必要があり、O(n)の時間がかかります。逆に、挿入・削除はポインタリストの方が効率的（O(1)）で、配列リストは要素の移動が必要なためO(n)の時間がかかります。

![シフト演算と加算の乗算フローチャート](./images/q5_1.png)

|   | a | b |
|---|---|---|

| イ | $Y$の第 0 ビット | $X$ を 1 ビット右シフト，$Y$ を 1 ビット左シフト |

## 問6

関数 $f(x, y)$ が次のとおり定義されているとき，$f(775, 527)$ の値は幾らか。ここで，$x$ mod $y$ は $x$ を $y$ で割った余りを返す。

$f(x, y)$: if $y = 0$ then return $x$ else return $f(y, x$ mod $y)$

- ア. 0
- イ. 31
- ウ. 248
- エ. 527

**正解: イ**

これはユークリッドの互除法による最大公約数の計算です。
- f(775, 527) → f(527, 775 mod 527) = f(527, 248)
- f(527, 248) → f(248, 527 mod 248) = f(248, 31)
- f(248, 31) → f(31, 248 mod 31) = f(31, 0)
- f(31, 0) → 31を返す

したがって、775と527の最大公約数は31です。

## 問8

動作クロック周波数が 700MHz の CPU で，命令実行に必要なクロック数及びその命令の出現率が表に示す値である場合，この CPU の性能は約何 MIPS か。

| 命令の種別 | 命令実行に必要なクロック数 | 出現率（%）|
|----------|---------------------|---------|
| レジスタ間演算 | 4 | 30 |

- ア. 10
- イ. 50

## 問9

キャッシュの書込み方式には，ライトスルー方式とライトバック方式がある。ライトバック方式を使用する目的として，適切なものはどれか。

- ア. キャッシュと主記憶の一貫性（コヒーレンシ）を保ちながら，書込みを行う。
- イ. キャッシュミスが発生したときに，キャッシュの内容の主記憶への書き戻しを不要にする。
- ウ. 個々のプロセッサがそれぞれのキャッシュをもつマルチプロセッサシステムにおいて，キャッシュ管理をライトスルー方式よりも簡単な回路構成で実現する。
- エ. プロセッサから主記憶への書込み頻度を減らす。

**正解: エ**

ライトバック方式は、書き込み時にキャッシュのみを更新し、主記憶への書き込みを遅延させる方式です。主記憶への書き込みは、そのキャッシュラインが追い出される時にのみ行います。これにより主記憶への書き込み頻度を大幅に減らすことができ、システム全体の性能向上につながります。一方、ライトスルー方式は毎回主記憶にも書き込むため、一貫性は保たれますが書き込み回数が多くなります。

- ア. 一連の大きな処理を一括して実行しなければならないので，並列処理が困難な処理が中心のシステム
- イ. 参照系のトランザクションが多いので，複数のサーバで分散処理を行っているシステム

## 問16

四つのジョブ A〜D を次の条件で実行し印刷する。全ての印刷が完了するのは，ジョブを起動してから何秒後か。

【条件】
(1) ジョブは一斉に起動され，多重度 1 で実行される。
(2) 優先順位は A が最も高く，B，C，D の順に低くなる。
(3) 各ジョブの実行後，スプーリング機能が 1 台のプリンタを用いて逐次印刷を行う。
(4) 各ジョブを単独で実行した場合の実行時間と印刷時間は，表のとおりである。

|--------|---------|---------|

| B | 30 | 40 |
| C | 20 | 30 |

単位：秒

- ア. 100
- イ. 160
- ウ. 190
- エ. 280

**正解: ウ**

多重度1なので実行は順次行われ、優先順位によりA→B→C→Dの順で実行されます。

- C：140秒開始、170秒完了
- D：170秒開始、190秒完了

全印刷完了は190秒後です。

## 問17

図の送信タスクから受信タスクに $T$ 秒間連続してデータを送信する。1 秒当たりの送信量を $S$，1 秒当たりの受信量を $R$ としたとき，バッファがオーバフローないバッファサイズ $L$ を表す関係式として適切なものはどれか。ここで，受信タスクよりも送信タスクの方が転送速度は速く，次の転送開始までの時間間隔は十分にあるものとする。

![バッファモデル図](./images/q17_1.png)

- ア. $L < (R - S) \times T$
- イ. $L < (S - R) \times T$
- ウ. $L \geqq (R - S) \times T$
- エ. $L \geqq (S - R) \times T$

**正解: エ**

送信速度S > 受信速度Rなので、バッファにはデータが蓄積されます。1秒間にバッファに蓄積されるデータ量は(S-R)です。T秒間送信すると、最大で(S-R)×Tのデータがバッファに蓄積されます。オーバフローを防ぐには、バッファサイズLがこの最大蓄積量以上である必要があります。したがって、$L \geqq (S - R) \times T$が正解です。

1, 3, 2, 1, 4, 5, 2, 3, 4, 5

のとき，ページを置き換える回数の組合せとして，適切なものはどれか。

|   | FIFO | LRU |

| イ | 3 | 6 |

**正解: エ**

**FIFO（First In First Out）**：
1,3,2→[1,3,2] | 1→hit | 4→[3,2,4]置換 | 5→[2,4,5]置換 | 2→hit | 3→[4,5,3]置換 | 4→[5,3,4]置換 | 5→[3,4,5]置換

不正競争防止法における営業秘密の3要件：
1. **秘密管理性**：秘密として管理されていること
2. **有用性**：事業活動に有用な技術・営業情報であること
3. **非公知性**：公然と知られていないこと（選択肢ウ）

この3要件を満たす情報が「営業秘密」として法的保護を受けます。特許出願や期間制限、譲渡可能性は要件ではありません。
